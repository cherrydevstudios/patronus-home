# Patronus Home — GitHub Pages site

This folder is ready to publish with GitHub Pages.

## Files
- `index.html` — homepage
- `privacy.html` — public privacy policy
- `support.html` — public support page
- `style.css` — shared styling

## Publish with GitHub Pages

1. Create a new **public** GitHub repository, for example:
   `patronus-home`
2. Upload all four files in this folder to the repository root.
3. On GitHub, open:
   **Settings → Pages**
4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Click **Save**.
6. Wait a minute or two for GitHub Pages to publish.

Your URLs will normally look like:

- Homepage:
  `https://YOUR-GITHUB-USERNAME.github.io/patronus-home/`
- Privacy policy:
  `https://YOUR-GITHUB-USERNAME.github.io/patronus-home/privacy.html`
- Support:
  `https://YOUR-GITHUB-USERNAME.github.io/patronus-home/support.html`

## Chrome Web Store fields

Use:
- **Homepage URL:** your GitHub Pages homepage URL
- **Support URL:** the `/support.html` URL
- **Privacy Policy URL:** the `/privacy.html` URL

## Optional improvements

After creating the repository:
- Enable **Issues** for bug reports.
- Replace the support-page placeholder with your actual GitHub Issues URL.
- Add a support email if you want users to contact you privately.
