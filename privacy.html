Patronus Home Privacy Policy

Last updated: September 20, 2026

Patronus Home does not sell personal data, display advertising, or include analytics or behavioral tracking.

Information stored by the extension

Patronus Home stores information you choose to provide or configure, such as your display name, selected spirit artwork, shortcut tabs, shortcut URLs, and extension preferences.

Where this information is stored

This information is stored using Chrome extension storage so the extension can remember your personalized homepage settings. Patronus Home does not operate an external server for collecting this information.

Website favicons

When you add a shortcut, Patronus Home may use Chrome's favicon functionality to display the icon associated with the website URL you provided.

Browser search

Searches entered into the homepage search field are handled through Chrome's Search API using the user's selected default search provider. Patronus Home does not change the user's default search provider and does not independently collect or store search queries.

Data sharing and sale

Patronus Home does not sell your data and does not share your extension preferences with advertisers or data brokers.

Analytics and advertising

Patronus Home does not include third-party analytics, advertising networks, or tracking scripts.

Removing your data

You can remove extension data by deleting your shortcuts and preferences or by uninstalling Patronus Home from Chrome.

Chrome Web Store User Data Policy

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

If Patronus Home's data practices change, this page will be updated to reflect those changes.

Contact

For privacy or support questions, use the contact details provided on the Support page.
